# vems

Small everyday toolkit for Python scripts: safe file reading, logging, and finish notifications.

## Install

    pip install vems

## What's inside

- **Safe CSV reading:** reads CSV files regardless of their text encoding, so scripts don't break on files exported from different systems.
- **Read as text:** an option to load every column as text (`str`) so data types aren't guessed.
- **Script logging:** sets up a log for your script and saves it in a folder on the Desktop.
- **Finish notification:** shows a desktop notification and plays a sound when a script ends.
- Other small utilities I use day to day.
